### 真缺陷：峰标签在峰分接近满格时被 SVG 视口裁掉

**症状**：感情 K 线「时辰线」卡片上「最高」二字的**字形顶部被切掉**，另外三张正常。

**机制**（探针反推，不是猜）：`PeakMark` 把说明放在 `cy - 30`，而**峰点本身就可以位于绘图区顶边**
（那正是「峰」的定义），顶边 = `margin.top`。所以需要 `margin.top ≥ 30 + 实测上升部 9 = 39`，
而当时是 **34**。实测字形框落在相对 y **-5…7**，surface 从 0 开始 → **顶上 5px 被 SVG 视口裁掉**，
而 `getComputedStyle().clipPath` 查不出来（就是附录里那条：SVG viewport 裁剪 ≠ CSS 裁剪）。

**为什么之前没显形**：八字序列的峰在 **80** 分附近；感情「时辰线」的峰**打到 100**，正好压到顶边。
阈值约 **峰分 > 90（compact）/ > 97（full）** —— 即**这个缺陷在 full 变体里一直存在，只是没被数据触发。**

**修法**：把净空变成有名常量并让它定 `margin.top`（`kline-geometry.ts`）：
`PEAK_CAPTION_OFFSET = 30` + `PEAK_CAPTION_ASCENT = 12`（实测 9，向上取整）→ `PEAK_CAPTION_HEADROOM = 42`。
`PeakMark` 用 OFFSET、图表用 HEADROOM —— **两处必须一致而类型系统连接不了**，所以放一起并写清理由。
修后实测字形框顶部 **-5 → +3**（3px 余量），与算式吻合（-5 + 8 = 3）。
守卫：`kline-chart.test.tsx` 造峰分 = 100 的序列，断言 `y - PEAK_CAPTION_ASCENT >= 0`（行为断言，
不是「margin 等于常量」的同义反复）。变异（margin 改回 34）→ 红 1 条 `expected -8 to be ≥ 0`。

### 一个阴性结果也记下来：低点箭头**不会**溢出

顺着同一条线怀疑对称问题：`TroughMark` 箭头画在 `cy + 5`，形状纵向 8…22 × 0.58 → **低点下方 17.8px**。

→ **不需要改，也不该为了「对称」去挤掉 sparkline 的绘图高度。记下来，下次不必重新量。**

### CSS：按规则删，不按文本删

8 个不再渲染的类散布在两个 CSS 文件里，有五种结构会让正则出错：**@media 多一层**、**逗号分组里只有

### 脚本自己又踩三个坑

1. **BEM 子类全没识别**：`\.name(?![\w-])` 的 lookahead 里 `_` **是** word 字符 → `.name__child` 不匹配。
   BEM 必须显式前缀判定（`===` 或 `__`/`--`），**不能靠 lookahead**。
2. **`overlapping edits` 抛错（没写盘）**：`nodeStart` 把**前导空白**也算进去，而上一条规则的
   「向后吞空白」正好吞同一段 → 两条编辑重叠 4 字符。**断言挡住了它**。修法：`nodeStart` 从去掉前导空白算起。
3. **空裁剪 `TRIM drop: []`** 与 `:not()` 简化范围重合 → 「没成员被丢」时不该产生编辑。

**外加一条**：我用 Python 核对 JS 报的 offset 觉得「错位」，一度怀疑解析器坏了 —— 实际是
**Python 按码点、JS 按 UTF-16 单元**。**跨语言核对 offset 前先确认单位。**
顺带给解析器加了自检（`text[preludeEnd] === "{"` 且 `text[nodeEnd-1] === "}"`）——
**自检通过才敢把怀疑从「解析器坏了」转到「单位不同」。**

### 怎么证明删 CSS 是惰性的（推理不算证据）

- **前提在真浏览器里量**：遍历 `querySelectorAll("*")`，4 个视口下都是 **0 个元素**带这 8 个类。
- **结论用 computed style 差分**：`:not()` 简化会把 specificity `(0,2,0)`→`(0,1,0)`，可能翻转胜者。
  对 **9 元素 × 4 视口 = 36 组**记 **33 个计算属性 + 包围盒** → **0 处差异**。
  视口特意含**满足**那条媒体查询的 `1440x1600` 和**不满足**的三个 —— 只测命中态会漏掉
  「简化后原本落空的规则反而生效」。

# 神数条文库数据来源（`src/lib/tieshen/data/*.json`）

本目录只放**可核对来源与许可**的神数索引表与条文断词，禁止手工新增、改写或"补全"条文。

### 为什么要单独落一个数据文件
- 该仓库把 14 张索引表与 12000 条条文断词打包成 `js/db-data.js`（497 KB）。本仓只取其**数据**（`tables` / `rule_tables` /
  `HEXAGRAM_MAP` / `HEXAGRAM_DETAIL_MAP` / `DESTINY_DATA` / `LIUNIAN_*` / `MARKER_TABLE` / `LETTER_TABLE` /
  `DATA_BY_LETTER` / `FORTUNE_DUANYU_MAP`），重排为下面 4 个 JSON，未复制其任何算法代码。
- `DATA_BY_CORRECTION` 与 `CORRECTION_TO_LETTER` 未单独落盘：它们可由 `DATA_BY_LETTER` 的行序（同一「条文校正数+岁数」
  取**末次出现**）推出，已用上游 `db-data.js` 逐键比对一致（1493 键），见 `data.ts` 的 `deriveCorrectionMaps`。

| 文件 | 内容 |
| --- | --- |
| `tables.json` | 14-1/14-2（月表、时支表）、14-3（五音表）、14-4（五音数）、14-5（日命表）、14-6（时运表） |
| `rules.json` | 14-7（考刻规则表）、14-8/14-9（卦名简表/详表）、14-10（本命条文偏移表） |
| `liunian.json` | 14-11-1/14-11-2（流年起始/流年五音序列）、14-12（流年标记）、14-13（流年字母）、14-14（字母×岁数→条文基加数） |
| `tiaowen.json` | `List.csv` 条文断词 12000 条，按「年龄⇥断词」单串存放，编号自 1001 起连续推出 |

## 未接入（本仓不生成对应条文）

- **邵子神数**（通行 6144 条谱）：检索到的实现（如 `Horace-Maxwell/horosa-skill`）为 AGPL-3.0，本仓不使用；公共领域
  古籍《邵子神数》均为民间抄本，版权状态不确定，故不采用。本页只保留导入接口，不生成邵子条文。
- **六亲条文（父母宫 / 兄弟宫…）条文字号**：上游仓库以「关键词启发式」把断词归入六亲，属现代启发式而非传统编号规则，
  本仓不采用；未获可核验的公开编号规则，未实现。
- **12000 条以外的通行「12000 条歌诀」异本、扫描件、OCR 文本**：一律不接入。

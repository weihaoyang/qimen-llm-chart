# 胜天半子：产品宪法

> 版本：v1.0
> 状态：已确认的产品方向
> 适用范围：产品、交互、数据模型、AI 输出、商业设计与后续研发的共同约束

## 1. 产品是什么

**胜天半子是给资源处于劣势者的现实极限博弈终端。**

它面对的“天”，不是玄学天命，而是冰冷的现实规则、阶层重力、资源差、时间、组织、市场、合同与人的有限性；“半子”不是侥幸，而是在无法全盘取胜时，用有限筹码在关键支点夺回的一点主动权。

产品只做一件事：在现实硬约束下，帮助用户盘清手牌、看见默认下坠线、识别时间与资源的交叉点，找到合法且可验证的非对称打法，并把一手行动落实到现实、追踪结果、修正下一局。

```text
冷酷盘点 → 默认重力线 → 现实交叉点 → 非对称推演
→ 强攻 / 试局 / 对冲 → 落子执行 → 物理结果 → 冷酷复盘
```

它不是：

- 算命软件、玄学神棍片或“命运预测器”；
- 泛化聊天机器人、情绪安慰工具或鸡汤产品；
- 替用户做决定、许诺翻盘或伪造胜率的系统；
- 教用户操纵、欺骗、违法或规避规则的工具。

## 2. 设计原则

1. **现实优先。** 现金、合同、健康、法律、能力、市场和已验证事实永远高于叙事与传统解释。
2. **硬约束先行。** 没有可用时间、资金、能力或合法路径的策略不能被包装成机会。
3. **默认下坠线可见。** 先承认常规路径的代价和惯性，再谈破局。
4. **非对称而非蛮力。** 劣势方不应与资源更强的一方做同维度、正面、长期消耗战。
5. **每一手必须可验证、可止损。** 没有验证信号、截止时间和止损条件的方案不算策略。
6. **版本不可篡改。** 当时的事实、假设、决策、止损线和结果必须可回看，不能被新结论静默覆盖。
7. **不确定性显式化。** 缺数据就说明缺什么，不能把推测写成概率或事实。
8. **AI 后台化。** 前台主角是局势、筹码、窗口、行动和结果；AI 是推演官，不是聊天主角。

## 3. 核心对象与统一命名

| 对象 | 含义 |
|---|---|
| 战局 | 一个有目标、对手、期限、约束和代价的具体现实问题。 |
| 底牌 | 当下实际可调动的现金、时间、能力、关系信用、信息与资格。 |
| 重力线 | 在不改变关键变量、按常规路径行动时的基准情景。 |
| 交叉点 | 时间窗口、资源瓶颈、外部变化、关键关系与风险重叠的可争节点。 |
| 落子 | 有执行人、期限、投入、验证信号、止损线的现实行动。 |
| 世界线 | 同一交叉点下，由不同策略形成的后续路径；是条件化推演，不是预言。 |
| 战报 | 落子后的实际事实、成本、反馈和结果。 |
| 博弈档案 | 跨战局沉淀的个人筹码、误判模式、有效打法和边界。 |

## 4. 用户端功能

### 4.1 开局：战局创建与战局采集

用户先“开一局”，而不是直接和 AI 闲聊。系统采集并持续补全：

- 要赢什么、最低可接受结果、理想结果；
- 对手或重力来源：人、公司、组织、规则、市场、时间或现金压力；
- 硬期限和错过后的物理后果；
- 当前已发生的可验证事实，以及已做过但无效的尝试；
- 不可触碰的法律、健康、现金、合同、家庭和职业信用红线；
- 可动用底牌和关键未知变量。

AI 每次只追问一个最能改变结论的变量，并强制标记用户输入为：**事实 / 推测 / 假设 / 情绪 / 目标**。用户可以跳过，但系统必须标注该战局的相应不确定性。

产物为《战局卡》：

```text
目标 / 对手 / 硬期限 / 当前损失 / 可用底牌 / 红线 /
已知事实 / 关键未知变量 / 当前阶段
```

### 4.2 左侧：冷酷底牌与现实约束栏（Cold Inventory）

#### 生存跑道

- 可支配现金、固定支出、净现金流；
- 现金断裂倒计时（按天）；
- 负债和可承受损失上限；
- 已承诺未到账收入，并标明兑现不确定性；
- 最低生存模式下可维持时间。

#### 时间与精力

- 每周可投入时间；
- 不可挤压的工作、家庭和健康时间；
- 并行战线数、连续高压耐受天数、过载等级；
- 每个策略需要的最小完整时间块。

#### 硬筹码池

每张筹码记录：类型、稀缺性、可验证证据、可调用时点、使用成本、可否复用、暴露后是否失效、对哪些对象有效。

类型包括但不限于：技术、作品、客户、渠道、数据、资质、现金、信息、地域和不可替代交付能力。

#### 人际信用池

人际关系只被视为有限信用额度，而不是联系人名单：关键人的决策权与利益诉求、关系强度、历史兑现、可请求事项层级、动用成本、利益冲突和不可再透支边界都必须可见。

#### 硬约束

法律与合规、合同义务、健康下限、家庭责任、职业信誉、不可公开信息和不可失去关系必须以不可绕过的红线存在。

### 4.3 外部重力场与默认重力线（Default Gravity Line）

系统将外部现实显式建模：

- 行业周期、市场变化、政策和公开规则；
- 竞争者或利益方的资源规模与组织层级；
- 对方真正的考核指标、激励和决策链；
- 用户位置的可替代性；
- 机会窗口、依赖关系和关闭条件。

每一局必须生成“默认重力线”：在用户不改变关键变量、继续采用常规路径时的基准情景。它必须写清常规做法、资源消耗、时间成本、可能的普通结果、主要失败原因、不可变变量、证据来源和不确定性；它不是人生预言。

### 4.4 中央：现实交叉沙盘（Intersection Graph）

中央主界面是一张可跳跃的**时间—因果—资源图**，不是聊天框或单向日历。

#### 节点类型

- 已发生事实、已做选择、资源变化、关系事件；
- 外部规则变化、机会窗口、风险事件、当前困局；
- 已落子行动、验证结果与未来待验证节点。

每个节点带有时间范围、影响范围、事实/假设/推演标签、关联筹码、关联主体、风险等级、窗口倒计时和证据来源。

#### 因果与时间跳跃

节点间可标记：导致、加速、阻断、依赖、冲突、重复模式、验证、资源继承与关系传导。

用户点击当前死局，应能向过去跳转，看到其来源；也能向未来跳转，看到未验证的策略分支。系统必须区分“已证实因果”与“AI 推测关联”。

#### 交叉点

当时间窗口、资源瓶颈、外部冲突、关键关系、用户筹码或不可逆风险至少两类重叠时，形成交叉点。交叉点按：紧急性、杠杆率、不可逆性和窗口半衰期排序。

每个交叉点展示：

```text
窗口剩余时间 / 核心变量 / 可动用底牌 / 默认后果 /
可验证信号 / 尚缺信息 / 下一步可选动作
```

#### 幽灵对照线

未选路径可作为反事实假设保留，用于复盘和比较；必须显示其依赖条件，不能伪装成“本应发生的人生”。

### 4.5 机会雷达与行动窗口监控（Action Window Monitor）

系统不只等用户提出困境，也帮助用户识别可争位置。用户可录入或授权接入公开、合法的信息：申报、招聘、投标、项目、考试、谈判、合同、融资等截止日；关键人决策周期；公开行业和政策日程；个人现金、精力与项目节点。

系统输出：

- 即将关闭的窗口；
- 可低成本试探的机会；
- 窗口与现有底牌的匹配度；
- 同时发生的资源冲突；
- 必须放弃的低优先级战线；
- 最佳行动期、衰减期、关闭时间和替代路径。

提醒必须回答“再等一段时间具体会失去什么”，而不只是推送截止日期。

### 4.6 右侧：非对称落子推演台（Asymmetric Strike Console）

用户选定一个交叉点后，系统必须生成至少三类合法策略：

| 策略 | 含义 | 适用条件 |
|---|---|---|
| 强攻手 | 集中资源击穿一个局部缺口 | 有明确窗口、筹码稀缺、可承受失败 |
| 试局手 | 低成本探针验证关键假设 | 信息不足、行动可逆、时间尚可 |
| 对冲手 | 立即锁定底线、停止承受损失 | 主战场不可赢、跑道不足或风险不可逆 |

每一手必须有：

- 唯一要解决的关键变量；
- 可执行动作清单、执行人、时间和依赖；
- 现金、时间、精力、人际信用与机会成本；
- 预期上行、最坏结果、失败承伤上限；
- 成功信号、证伪条件、最晚验证时间；
- 止损条件、失败后的下一手；
- 计算和推演依据、信息缺口与不确定性。

#### 风险收益矩阵与 0.5 Delta Index

比较每一手相对默认重力线的：上行空间、成本、可逆性、外部依赖、信息完备度和不确定性。

`0.5 Delta Index` 只衡量该策略夺回的选择权与现实主动权，不伪装为成功概率或预言。

#### 对手盘与漏洞扫描

仅分析公开、合法且职业伦理范围内的利益诉求、考核指标、组织瓶颈、信息差、流程空档、服务缺口与竞争者的成本边界。禁止生成欺骗、胁迫、非法取证、规避监管、侵犯隐私或伤害性建议。

### 4.7 落子执行台（Commit & Lock）

“落下这一子”是创建不可静默覆盖的决策版本，而不是普通保存。

系统生成《落子令》：

```text
战局 / 目标 / 选择的策略 / 第一动作 / 执行人 / 开始时间 /
硬截止 / 资源投入 / 成功信号 / 失败信号 / 止损线 /
备选动作 / 当时依据 / 当时未知信息
```

执行功能：

- 行动清单、执行顺序和进度状态；
- 倒计时、日历提醒和关键节点提醒；
- 实际资源消耗与预算对比；
- 事实附件：合同、报价、纪要、数据、截图与链接；
- 未按时执行或关键假设失效时，提示启动对冲或重开推演；
- 改线必须创建新版本，并记录变化的事实和失效的旧假设。

### 4.8 风险断路器（Circuit Breaker）

每一个落子至少绑定一个断路器：

- 现金断路器；
- 时间断路器；
- 关系信用断路器；
- 精力与健康断路器；
- 法律与合规断路器；
- 核心假设证伪断路器；
- 更高杠杆机会出现时的切换断路器。

当用户违反自己设定的条件时，系统必须清晰指出，而不是以“再坚持一下”鼓励沉没成本。

### 4.9 冷酷复盘引擎（Cold Post-Mortem）

战局结束或到达验证节点后，系统比较当时判断与后来的物理事实：

- 哪些假设成立、哪些错误；
- 错在信息、推理、资源估值还是执行；
- 哪项筹码和风险被高估或低估；
- 是否违反止损规则；
- 哪项打法产生真实杠杆；
- 下一次同类战局应自动采用什么修正规则。

输出：决策质量、信息误判率、资源估值偏差、时间估计偏差、风险偏好偏差、关系信用使用质量与个人规则修正。决策质量评价的是当时信息下的判断和执行，不能用后来成败倒推。

### 4.10 长期博弈档案

多局之间必须沉淀为个人战略画像：

- 可持续硬筹码与长期短板；
- 反复出现的死局和错误模式；
- 常被高估或低估的能力、风险与关系；
- 最有效的破局方式、最适合与最不适合进入的战场；
- 有效合作对象类型；
- 个人资源跑道历史；
- 已验证的止损边界；
- 个人“半子公式”：何种条件下最可能夺回选择权。

## 5. AI 的职责与限制

AI 是后台推演官，负责追问缺失变量、拆分事实/假设/情绪、发现冲突、生成重力线、形成非对称策略、标明证据和信息缺口、将结果写入复盘与档案。

AI 不得：

- 承诺翻盘、成功、胜率或命运结果；
- 用未输入的数据补造事实；
- 将情绪安慰当成策略；
- 给出违法、不道德、欺骗、操纵或高伤害建议；
- 把传统术数解释包装成物理因果。

## 6. 术数的正确位置

奇门、八字、紫微与 K 线仅是**可选的时间/心理周期观察叠层**，不是产品发动机。

- 现实事实默认置顶，术数默认折叠；
- 所有术数内容标为“传统解释参考”；
- 不得覆盖现金、合同、法律、健康、市场数据与已验证事实；
- 用户完全关闭术数叠层后，战局、推演、落子和复盘仍必须完整可用。

## 7. 必需的基础能力与商业边界

- 登录后持久化战局、行动、证据、决策版本和复盘；
- 未登录可体验，但清楚提示离开、刷新、换设备可能丢失；
- 一个购买解锁一个战局的完整生命周期，不按单条消息收费；
- 模型、网络或保存失败必须可见、可重试、不可吞错；
- 决策版本和保存状态可追溯；
- 用户可导出战局报告、落子令和复盘报告；
- 提供数据导出、删除、访问控制与敏感数据保护；
- 后续允许邀请可信协作者或人工顾问，但事实、AI 推演与人工意见必须分层显示。

## 8. 实现优先级

### P0：产品成立的最低闭环

1. 开局与战局采集；
2. 冷酷底牌盘点；
3. 默认重力线与硬死线；
4. 交叉点图最小版本；
5. 强攻 / 试局 / 对冲推演；
6. 落子令与执行清单；
7. 风险断路器；
8. 版本化冷酷复盘；
9. 登录保存、恢复、失败状态和完整战局权限。

### P1：形成“交叉点与长期博弈”体验

1. 因果图、时间跳跃和幽灵对照线；
2. 机会雷达、窗口半衰期和主动提醒；
3. 资源、人际信用、行动消耗的联动；
4. 长期博弈档案；
5. 报告导出；
6. 可选术数叠层。

### P2：生态扩展

1. 公开合法信息源与机会监测；
2. 可信协作者、导师与人工顾问协作；
3. 匿名同类战局模式库；
4. 多战局资源冲突与协同推演；
5. 基于长期真实反馈的个人策略校准。

## 9. 现有功能映射

现有“人生访谈、决策树、复盘、术数证据”并不废弃，但必须被重命名和重组：

| 旧称 | 新定位 |
|---|---|
| 人生访谈 | 战局采集 |
| 决策树 | 非对称推演 |
| 推进 / 验证 / 保护 | 强攻 / 试局 / 对冲 |
| 证据抽屉 | 情报与约束依据 |
| 复盘 | 冷酷归因 |
| 排盘与 K 线 | 可选时间/心理周期叠层 |

## 10. 验收标准

一个用户在没有打开任何术数模块的情况下，能够：

1. 录入一个真实战局；
2. 看见手中底牌、硬约束和默认下坠线；
3. 找到至少一个有截止时间和现实依据的交叉点；
4. 比较强攻、试局、对冲三种策略的成本、收益、验证和止损；
5. 落下一手并进入执行；
6. 在事实出现后复盘这一手的决策质量；
7. 在下一局中看到上一局形成的筹码、教训或约束。

做到以上，产品才配得上“胜天半子”。
